# W6 — Test v2 on real phones

This test closes phase 3. Do the test on real phones. Do not use a simulator.

## 1. What you need

- An iPhone that has a notch. Use the Safari browser.
- An Android phone. Use the Chrome browser.
- Your account on the production website.
- The v2 switch must be on (Settings → Developer).

Do the full test one time on each phone.

## 2. How to report a problem

If a step fails, write down these four items:

1. The phone model.
2. The browser.
3. The step number.
4. What you saw.

Send me the list. I will repair the problems.

## 3. Keyboard tests

1. Open the home page. Tap the message box. Make sure that the keyboard does not
   hide the message box.
2. Keep the keyboard open. Turn the phone on its side. Turn it back. Make sure
   that the message box stays above the keyboard.
3. Open a conversation. Tap the message box at the bottom. Make sure that the
   box rises above the keyboard. Make sure that the page does not jump.
4. iPhone only: scroll a long conversation up and down. The Safari toolbar
   becomes small and large. Make sure that the message box stays at the bottom.
   Make sure that there is no white strip at the bottom of the screen.
5. Type a message that has many lines. Make sure that the box stops growing at
   some point and scrolls inside itself. Make sure that you can always see the
   send button.
6. Open the "Conversations" page. Tap the search box. Make sure that the page
   does not zoom in.

## 4. Screen edge tests

7. Look at the top of the screen. Make sure that the camera notch does not hide
   the header. Turn the phone to each side. Look again.
8. Open a conversation. Make sure that the bottom bar of the phone does not
   hide the message box.
9. If you have a small phone: look at the header. Make sure that the items in
   the header do not touch each other. Make sure that a long conversation title
   shows "…" and does not push other items away.

## 5. Touch tests

10. Tap each of these buttons. Make sure that each one is easy to hit with a
    finger: the menu rows, the recent conversations, the send button, the X in
    the search box, the Delete button in a confidential conversation.
11. In an AI answer, tap a case name (a gold link). Make sure that a small
    preview card opens. Make sure that the page does not change. Tap "Open
    case" in the card. Make sure that the case page opens.
12. Go back. Tap the case name again. Tap outside the card. Make sure that the
    card closes smoothly.
13. Touch and hold a case name. Make sure that the phone shows its usual link
    menu.
14. Find an answer where the AI used tools. You see "N tool calls completed".
    Tap it. Make sure that all the steps show with a smooth movement. Tap it
    again. Make sure that they hide with a smooth movement. Tap one step. Make
    sure that its details open smoothly. Tap it again to close. Nothing must
    jump.
15. Open the side menu. Tap "Library". Make sure that the group closes with a
    smooth movement. Tap it again. Make sure that it opens with a smooth
    movement. Scroll down the "Recent" list. Make sure that more conversations
    load. Tap one. Make sure that it opens.

## 6. Full task tests

16. On the home page, send a message from each tab: Chat, Work, Study. Make
    sure that the answer streams in. Open the side menu. Make sure that the new
    conversation is at the top of "Recent". Do not refresh the page.
17. Open an old conversation. Send a message. Open the side menu. Make sure
    that this conversation moved to the top of "Recent". Do not refresh the
    page.
18. Confidential test, part 1: tap the + in the message box. Select
    "Confidential mode". Read the small text. Make sure that it says "Stored
    only on this device until you delete it".
19. Confidential test, part 2: send a message in the confidential conversation.
    Reload the page. Make sure that the conversation is still there.
20. Confidential test, part 3: tap "Delete" in the green bar. Confirm. Make
    sure that you go to the home page. Open the conversation link again if you
    can find it. Make sure that the content is gone.
21. Open the "Conversations" page. Scroll down. Make sure that more rows load
    before you reach the bottom. You must not wait at the bottom.
22. Type a word in the search box. Make sure that the list filters. Make sure
    that the web address shows your search word. Tap the X. Make sure that the
    full list comes back.
23. On the "Conversations" page, find an archived conversation. Make sure that
    it shows an "Archived" label. Find a confidential conversation. Make sure
    that it shows a green shield. Tap a row. Make sure that it opens.
24. Use a phone where you are not signed in. Open the website. Make sure that
    the home page shows. Open the "Conversations" page. Make sure that it asks
    you to sign in. Make sure that nothing is broken.

## 7. Dark mode and motion tests

25. Set the phone to dark mode. Do steps 11, 14, 15, and 18 again. Make sure
    that you can read all the text.
26. Turn on "Reduce Motion" in the phone settings. Use the app for one minute.
    Make sure that things appear immediately, without animation. Make sure that
    nothing is broken.

## 8. When the test is complete

Phase 3 is complete when:

- All the steps pass on the iPhone and on the Android phone.
- The testers use v2 chat for their daily work.

Then tell me. I will write the phase-3 close-out document and start phase 4.
