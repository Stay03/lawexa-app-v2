What to check (A/B them)

Watch both rings together for ~30s, then focus one field, then toggle theme.

Idle wander, not a spin. The light drifts along an irregular path — pausing, doubling back — never a steady rotation.
Speed feel. One idle cycle ≈ 25s. It should read as ambient, not fast.
Focus slowdown + palette. Click into a field: gold gives way to cool whitish-blue (light) / silver-gold (dark) and slows to ≈45s.
Dark mode. Toggle theme — both rings switch to the vibrant dark palette and stay matched.
1px ring crispness. The gold is a hairline; the inner surface (radius 11px) sits inside the 12px outer with no seam.
Reduced motion. Toggle "Reduce motion" — both settle to the same static gold ring, no animation.

Mapping: background-position X% Y% ≡ translate(−0.875·X%, −0.875·Y%) of a layer sized 800%×800% (derivation in the source comment). The map is a linear scalar, so ease-in-out on translate eases the visible window identically. Focus crossfade: the rebuild keeps two layers — base (25s) and focus (45s) — always running, and crossfades opacity over 0.3s on :focus-within (the original's transition: background .3s is effectively an instant palette swap, so the only honest difference is the two layers' independent phase at the moment of focus — imperceptible on a 25–45s ambient drift).
